## Profile

At ServiceNow, I develop AI Agent Studio capabilities for planning, orchestration, and ReAct task execution. My work covers multi-step workflows, permission-aware tool use, shared enterprise context, and recovery from failed attempts. I evaluate agent behavior across task completion, tool validity, robustness, model compatibility, latency, and cost.

Previously at KLA, I developed machine learning and computer vision algorithms for semiconductor defect inspection, built training and preprocessing pipelines, and worked with engineering teams to integrate models into products. I hold a PhD in Computer Science from West Virginia University, where my research focused on activity recognition, multi-view sensor fusion, and image classification.
